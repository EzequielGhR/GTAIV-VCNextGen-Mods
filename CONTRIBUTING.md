# Contributing to GTAIV-VCNextGen-Mods

First off, thank you for your interest in contributing! Contributions of all kinds are warmly welcomed and appreciated.

This is a passion project and a hobby repository. To keep things smooth, maintainable, and enjoyable for everyone, please keep the following guidelines in mind when contributing.

---

## 🤖 A Note on AI Usage

This project is a personal hobby. **I do not use AI to write the actual code for this project**—I already spend enough time dealing with that at work! 

If you choose to use AI tools (such as ChatGPT, Claude, GitHub Copilot, etc.) to help craft your contributions, please adhere to these expectations:
- **Human-Readable & Maintainable:** Any AI-generated code or changes **must** be fully readable, understandable, and maintainable by humans. I will be reviewing, maintaining, and debugging the code myself, so readability and clean architecture are paramount.
- **My AI Tool of Choice:** In the rare occasions I do use AI for this repository (such as drafting descriptions, fixing typos, or exploring code layout), I use **OpenCode**. 
  - You will find a tracked `.opencode` folder in this repository containing an OpenCode configuration.
  - This configuration enforces asking for permission before reading files. This is primarily to keep tight control over what the model reads, helping preserve context and tokens when exploring the repository or refining text.

---

## 🛠️ Pull Request & Branching Workflow

- **Protected Main Branch:** The `main` branch is protected, and force-pushing is disabled.
- **Pull Requests:** All contributions must go through a Pull Request (PR) and require at least **1 approval** before merging.
- **Keep it Focused:** Try to keep PRs focused on a single feature, bugfix, or improvement to make review easier.

---

Thank you for helping make this project better! If you have any questions, feel free to open an issue or start a discussion.
