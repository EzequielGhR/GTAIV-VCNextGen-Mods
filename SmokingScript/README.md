# What it does

Makes Tommy invincible... what do you think it does?
- Hold NavDown (Down Arrow for controllers) to start smoking. This is just a wink to CERTAINDEATH iykyk.
- Tommy's (or maybe Niko's) life restores as he smokes, just like if you smoke in real life.
- The life regen is super slow but you can walk and run while smoking, but you can get interrupted if you do any other action.
- Hold NavDown again to stop smoking.

# How To

Just copy and paste SmokingScript.cs to your game folder/scripts
